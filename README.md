# # ☕ Bright Coffee Case Study

## 📌 Overview

This project is a **Bright Coffee Case Study** completed as part of my **Data Analytics studies at BrightLearn**.

The project involved analyzing coffee sales data, creating dashboards, planning the dashboard, and presenting the findings.

## 🎯 Objectives

* Analyze coffee sales data
* Identify sales trends and patterns
* Understand product performance
* Answer key business questions
* Present insights from the data
